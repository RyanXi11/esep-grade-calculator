# ESEP Grade Calculator

## Overview
This is a Go-based final grade calculator library. It computes a student's final grade by calculating the weighted average of three distinct categories: assignments, exams, and essays. It also converts the final numerical score into a standardized letter grade. 

## Requirements
- [Go](https://go.dev/dl/) (Ensure Go is installed and added to your system path)

## Setup & Execution
1. Clone the repository to your local machine.
2. Navigate to the project root directory.
3. To run the automated unit tests, execute the following command in your terminal:
   `go test -v`
4. To check code coverage, run:
   `go test -cover`
